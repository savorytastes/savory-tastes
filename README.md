# Savory Tastes website update

This version rebuilds the site around the recent Masala-ish Classic Masala package design.

## Upload to GitHub Pages

Upload these items to the root of the repository, replacing older versions when prompted:

- `index.html`
- `404.html`
- `CNAME`
- the entire `assets` folder

Commit the changes. GitHub Pages should publish automatically.

The displayed package artwork has been adapted for the website to remove the outdated net-weight line and registration symbol. Final ingredient order, nutrition information, claims, and package specifications should be updated after regulatory review and the final package dieline is approved.
